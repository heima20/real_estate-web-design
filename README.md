# SAIMO Real Estate

موقع عقاري 100% Frontend – لا يحتاج backend أو XAMPP أو Node.js.

## تشغيل المشروع

افتح ملف `public/index.html` مباشرةً في المتصفح، أو استخدم أي server ثابت مثل:

```
npx serve public
```

## الميزات
- تسجيل دخول وتسجيل (localStorage)
- تصفح وبحث وفلترة العقارات
- صفحة تفاصيل عقار + معرض صور
- نظام حجز وبطاقة دفع (محاكاة)
- لوحة تحكم Admin (إضافة/تعديل/حذف العقارات)
- كل البيانات محفوظة في localStorage
